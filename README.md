## Highlights

* **OLED-Optimized Dark Palette:** High-contrast warm neutrals paired with deep espresso accents.
* **Component-Driven Layouts:** Clean separation of product cards, custom bottom navigation, and pill badges.
* **Fluid Scroll Physics:** Bouncing physics tuned for natural tactile feedback on mobile screens.

---

## Getting Started

### Prerequisites
* Flutter SDK (3.x recommended)
* Dart SDK

### Installation

```bash
git clone https://github.com/Ghost-9/Coffee-App.git
cd Coffee-App
flutter pub get
flutter run
```
